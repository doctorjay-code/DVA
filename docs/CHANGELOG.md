# CHANGELOG

## v3.9.21 (2026-09-04)

### 🐛 버그 수정
- **세미나 퀴즈 Slack 알림 및 Block Kit 버튼 콜백 오류 수정**:
  - 세미나 퀴즈 답안 선택 버튼(Block Kit)을 전송할 때 발생하던 `TypeError: <lambda>() got an unexpected keyword argument 'blocks'` 오류를 수정했습니다.
  - 불필요한 중간 람다 래핑을 제거하고, Slack/Kakao 알림 콜백 시그니처가 `**kwargs`를 정상 수용하도록 통일하여 Block Kit interactive 버튼이 원활히 전송되도록 개선했습니다.
- **세미나 퀴즈 임의 선택(찍기) 및 오답 제출 방지**:
  - 퀴즈 질문 파싱 중 알림 전송 예외가 발생하더라도 답안 대기 루틴이 중단되거나 잘못 진행되지 않도록 격리했습니다.
  - `auto_fill_questions_in_order()`에서 퀴즈 판정 및 처리 중 예외 발생 시, 다음 문항으로 무작정 넘어가지 않고 즉시 설문 작성을 중단(`return False`)하도록 수정했습니다.
  - `retry_fill_missing_fields()`에서 미입력 필드가 퀴즈 문항(`[퀴즈]` 태그 포함)일 경우, 1번 보기를 임의로 자동 선택하던 동작을 완전히 차단하고 즉시 설문을 중단하여 오답 제출을 방지했습니다.
- **프로그램 종료 시 스코프 오류 수정**:
  - 빠른 종료 루틴(`fast_exit()`)에서 `os` 모듈 참조 순서로 인해 발생하던 `UnboundLocalError: cannot access local variable 'os'` 문제를 해결했습니다.
- **프로그램 실행 직후 과거 종료 명령으로 인한 즉시 꺼짐 방지**:
  - 슬랙/PC Agent에서 종료 신호를 보낸 직후 프로그램을 재실행했을 때, 디스크에 남아있던 과거 종료 신호를 새 명령으로 착각하여 켜지자마자 꺼지던 문제를 해결했습니다.
  - 프로그램 가동 시각(`app_start_time`) 이전에 생성된 과거 명령어는 완전히 무시하도록 필터링하고, 종료 처리 시 신호 파일 즉시 삭제 및 PC Agent 가동 시 잔여 파일 자동 정리(3중 방어)를 적용했습니다.

### ✨ 기능 개선
- **DVA 프로그램 시작/종료 실시간 알림 지원**:
  - **시작 알림**: 프로그램 실행 직후 `🚀 [{계정명}] DVA 프로그램이 시작되었습니다.` 알림을 Slack 및 카카오톡으로 발송하여 로그인 전에도 DVA의 가동 상태를 즉각 인지할 수 있도록 했습니다.
  - **종료 알림**: 프로그램 창 닫기 또는 정상 종료 시 `🛑 [{계정명}] DVA 프로그램이 종료되었습니다. (보유 포인트: ...)` 알림을 발송하여 종료 시점의 최종 보유 포인트와 상태를 전달합니다.
- **PC Agent 연동 원격 종료 지원 및 DVA 봇 알림 보장**:
  - PC Agent의 Slack 봇에서 "닥터빌 종료" 요청 시, 강제 프로세스 종료(`taskkill`) 전에 DVA IPC 채널(`slack_cmd_dispatch.json`)로 `{"task_name": "exit"}` 명령을 우선 전달하고 유예 시간(1.5초)을 부여하도록 개선했습니다.
  - 이를 통해 PC Agent를 통한 종료 시에도 DVA가 정상 종료 절차를 수행하며 DVA 자체 Slack 봇으로 종료 알림을 누락 없이 발송합니다.
  - DVA 자체 Slack 명령어에서도 `"닥터빌 종료"`, `"디바 종료"`, `"종료"`, `"꺼줘"`를 인식하여 자동 종료할 수 있도록 지원합니다.
- **Slack 알림 시스템 현대화 (신형 Bot API / 채널 ID 기반 전송)**:
  - 구형 고정 Webhook URL 방식에서 탈피하여, PC Agent와 동일하게 **Slack Bot API (`WebClient.chat_postMessage`) + 채널 ID** 기반으로 알림을 전송하도록 업그레이드했습니다.
  - 채널 변경 시 웹사이트에서 Webhook을 새로 발급받을 필요 없이, 슬랙 채널에서 봇을 초대(`/invite @dva_bj`)하고 채널 ID만 입력하면 즉시 변경됩니다.
  - 채널 미지정 또는 봇 미초대 시 기존 Webhook URL로 자동 폴백(Fallback)되어 알림 누락을 원천 방지합니다.
  - 설정창 UI에 `📢 채널 ID (권장)` 입력 필드 및 즉시 테스트 기능을 추가했습니다.

## v3.9.19 (2026-08-21)

### 🐛 버그 수정
- **Slack 숫자 답안 수신을 문제관리 대기 상태로 제한**: 공유 문제관리 창이 실제로 답안을 기다리는 동안(`survey_answer_prompt.lock` 유효)일 때만 숫자형·O/X형 답안을 해석하도록 변경했습니다. 평상시 채널의 숫자 메시지는 DVA가 무시합니다.
- **시간·날짜 문구의 답안 오인 차단**: 접두어 없이 입력하는 답안은 `234`, `O X O`, `2 3 4`처럼 답안 문자와 구분자로만 구성된 메시지 전체가 일치할 때만 허용합니다. 따라서 `KTX 진주 동대구 8월30일 08:00~09:00` 같은 일반 문장은 문제관리 대기 중에도 답안으로 처리되지 않습니다.
- **공개 채널의 불필요한 자연어 해석 제한**: 멘션 또는 DM이 아닌 일반 채널 대화에는 자연어 의도 해석을 실행하지 않아, 다른 봇 및 일반 대화와의 의도치 않은 상호작용을 줄였습니다.
- **Chrome 유출된 비밀번호 경고 차단**: 자동화용 Chrome 프로필에서 비밀번호 저장 제안 및 유출 감지를 비활성화해, 로그인 직후 경고 팝업이 루틴 화면을 가리는 문제를 방지했습니다. 안전 브라우징은 계속 활성화됩니다.

## v3.9.17 (2026-08-20)

### 🐛 버그 수정
- **다중 계정 Chrome 창 식별·복원 안정화**: 계정별 브라우저 창에 임시 고유 표식을 적용해 해당 인스턴스의 Chrome 창만 찾도록 개선했습니다. 다른 계정의 창을 잘못 최소화·복원하거나 제어하는 문제를 방지합니다.
- **창 핸들 유효성 재검증**: Chrome 창이 닫혔거나 유효하지 않은 경우 창 소유 프로세스와 핸들을 다시 확인한 뒤 재탐색하도록 보완했습니다. 대상 창을 찾지 못하면 다른 실행 중인 Chrome 창을 대신 제어하지 않고 안전하게 건너뜁니다.
- **Slack 쿠폰 액면가 정확 매칭**: Slack 쿠폰 구매 요청에서 상품명뿐 아니라 요청 금액도 함께 비교하도록 수정했습니다. `카카오페이 만원` 또는 `카카오페이 10,000원`은 카카오페이포인트 10,000P를, `카카오페이 5,000원` 또는 `오천원`은 5,000P를 선택합니다. 일치하는 액면가 상품이 없으면 다른 금액의 상품을 임의로 구매하지 않고 결제를 취소합니다.

### ✨ 기능 개선
- **일반 쿠폰 다중 구매 처리 보강**: 일반 상품이 수량 변경을 지원하면 한 주문으로 결제하고, 수량이 1개로 고정된 상품은 요청 수량만큼 순차 결제하도록 동작을 유지·검증했습니다.

  - 숫자 정답 자동 마이그레이션: 문제 풀이 시 DB에 저장된 기존 정답이 단순 숫자(예: `"1"`)인 경우, 현재 페이지에서 매칭되는 보기 텍스트를 추출하여 DB 정답을 실제 텍스트(예: `"서울"`)로 자동 업데이트합니다.
  - 보기 순서 변경 대처: DB에 저장된 정답이 텍스트인 경우, 보기 순서가 뒤바뀌어 표시되더라도 텍스트를 기반으로 매칭하여 올바른 라디오 버튼을 선택합니다.
